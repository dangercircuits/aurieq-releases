# Auri EQ for Android

**O equalizador do Kuba Auri no Android. Gratuito e não oficial.**

A Kuba Audio já oferece um equalizador web para o Auri. Esta adaptação preserva a interface e os presets originais e acrescenta a ponte USB que permite gravá-los no DSP do cabo usando um celular Android.

- Android 8.0+ com USB host (OTG).
- Funciona offline; não utiliza a internet.
- Requer autorização de acesso ao dispositivo USB quando solicitada pelo Android.
- Testado em Google Pixel 10; outros aparelhos não têm compatibilidade garantida.
- O preset gravado permanece no cabo.

**[Baixar a versão v1.0](https://github.com/dangercircuits/aurieq-releases/releases/tag/v1.0)**  
**[Instalação, compatibilidade e transparência](https://dangercircuits.com/labs/auri/)**

A página de release fornece o APK e o arquivo SHA-256 para verificação de integridade. Não confunda a existência de um APK público com a publicação do código-fonte.

**Créditos:** o equalizador original, os presets e a marca Auri são da [Kuba Audio](https://kuba.audio/). Esta adaptação é independente, mantida pela [Danger Circuits](https://dangercircuits.com), e não é um aplicativo oficial da Kuba.
